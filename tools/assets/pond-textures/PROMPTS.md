# GPT Image source prompts

These original production-source textures were generated with the built-in
GPT Image tool, then reduced with nearest-neighbour sampling for the in-game
pixel atlas.

## Lily pad

```text
Use case: stylized-concept
Asset type: production source texture for an original browser voxel-survival game's 3D lily-pad model
Primary request: create one original lily-pad pixel-art texture, designed to be downsampled to a crisp 32x32 game texture
Scene/backdrop: genuinely transparent background
Subject: top-down orthographic lily pad, near-round but deliberately block-stepped around the rim, one clean wedge notch, subtle central vein and a few chunky mottled pixel clusters
Style/medium: authentic low-resolution voxel-game pixel art; hard square pixels; nearest-neighbor look; handmade sprite texture; original design that does not copy any existing game texture
Composition/framing: centered, fills about 88% of a square canvas, perfectly top-down, no flower and no other object
Lighting/mood: flat readable game albedo, minimal baked shading
Color palette: rich moss green, fern green highlights, deep forest-green rim and veins; restrained natural contrast
Constraints: actual transparency outside the pad; silhouette must remain readable at 32x32; no antialiasing, no blur, no gradients, no glow, no shadow, no perspective, no text, no border, no watermark
Avoid: photorealism, glossy leaves, painterly brushwork, smooth vector edges, excessive detail, blue-green neon colors
```

## Lily flower

```text
Use case: stylized-concept
Asset type: production source texture for crossed planes on an original browser voxel-survival game's 3D pond-lily flower
Primary request: create one original front-facing pond-lily flower sprite, designed to be downsampled to a crisp 32x32 transparent game texture
Scene/backdrop: genuinely transparent background
Subject: one compact water-lily blossom with a very short dark-green stem; six to eight chunky square-stepped petals surrounding a small golden-yellow square center; flower only, no lily pad
Style/medium: authentic low-resolution voxel-game pixel art; hard square pixels; nearest-neighbor look; handmade block-built sprite; original design that does not copy any existing game texture
Composition/framing: centered, straight-on elevation view for use on two crossed billboard planes, fills about 78% of square canvas, balanced silhouette readable from a distance
Lighting/mood: flat readable game albedo, minimal baked shading
Color palette: warm ivory and very pale blush-pink petals, muted rose shadow pixels, ochre-gold center, deep moss stem
Constraints: actual transparency outside the flower; silhouette must remain readable at 32x32; crisp hard alpha edges; no antialiasing, no blur, no gradients, no glow, no shadow, no perspective, no text, no border, no watermark
Avoid: photorealism, smooth vector curves, painterly detail, neon colors, a long stem, leaves, extra objects
```
